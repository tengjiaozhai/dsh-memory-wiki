# Memory Wiki 界面

2026-10-24 用户选定：全景画布与侧边阅读浮层。批准参考为 `.impeccable/mocks/decision/graph-overlay.png`；对应 surface seed `03b9eae5`。这是 DSH 内的操作界面，宿主拥有应用导航。

## 布局

- 一条紧凑顶栏包含名称、标题/路径搜索、刷新和上下文入口。默认主区域只有整库关系图，不预留空候选列或空正文列。
- 页面节点用点与标签，边只表示真实 Wiki 正文链接和 related 字段。统一使用低曲率细线，不通过虚线区分来源；完整图谱不带检索评分或证据选中语义。
- 详情浮层桌面宽 400px，位于右侧，标题与关闭按钮、滚动正文、出链与反链、页面信息、选为依据操作依次呈现。点击节点时保留当前缩放，将节点移到左侧宿主导航与右侧浮层之间的可见画布中央；中心按浮层实际边界计算。
- 上下文为独立浮层，展示原有草稿与准备状态。它与正文使用同一浮层位置，不并排挤占画布。
- 宽度低于 700px 时顶栏搜索独占一行，详情占据主区域的阅读视图；保留关闭返回图谱入口。

## 视觉

- 根背景 `#171f27`，面板 `#212d39`，次表面 `#1c2733`，分界 `#344350`。
- 主文 `#e8edf4`，次文 `#a8b7c8`，选中与关联边 `#8bc7f4`；搜索命中点 `#efc366`，选中优先使用蓝色。
- 系统无衬线延续宿主。界面正文 13px，知识正文 14px / 1.85，浮层标题 23px。状态、路径和图例使用 11–12px，不依靠大标题或装饰背景争夺注意。
- 浮层圆角 12px，用有偏移的柔和阴影表达层级。图谱背景平静，不叠加霓虹、星空或装饰纹理。
- 图标为同一笔画系统的内联 SVG；图谱和 UI 保持矢量与语义控件，不需要运行时位图资产。

## 图谱密度与状态

全局空间布局采用 Graphology ForceAtlas2 + Noverlap，按真实链接一次性确定性计算；Sigma 3 的 WebGL 负责节点和边的缩放和平移，Canvas 绘制标签，不在相机事件中重建 React 节点或反向放大文字。标签使用库的标签网格防冲突和固定屏幕字号，使用库的标签避让和固定字号，不反向放大文字；选中和搜索命中优先展示。全量页面和链接始终保留，不能用假主题分类替代真实数据。

节点的视觉层级只来自真实无向连接度：真实连接度前 10% 且连接度 ≥10 的页面作为高连接枢纽（小库不机械凑满），使用更大的节点、15px 标题和浅色；普通页使用小节点和 12px 标题。这个阈值只控制浏览层级，不代表知识质量或内容权威。正文与 related 均使用 @sigma/edge-curve 的低曲率边，related 保留在真实边数据与详情关系中，不再用 v4 私有 picking 修补换取虚线样式。普通边保持低亮度，高连接端点相关边稍强，当前页的一跳边最亮。平行边由官方索引分配曲率，所有边继续保留。WebGL 不可用时显示明确错误，搜索和可键盘访问的页面索引仍可打开正文。

选中节点突出直接关系，其他节点和边淡化。正文独立按需读取；标题来自元数据，正文中的同名首标题省略，避免重复。加载、空库、读取失败与版本不符均明确呈现，失败不伪装成空库。

浏览、手选草稿、已准备覆盖、实际带入保持各自含义。准备按钮只有在页面、版本、顺序和问题与服务端草稿一致时启用。未绑定会话时可浏览知识，不能写会话状态。

运动仅用于浮层展开及视野变换；尊重减少动态效果偏好。键盘可访问搜索、结果、节点与关闭操作，Escape 返回图谱。

## 沉淀记录

顶栏“沉淀记录”打开独立内容视图；图谱保持挂载并保留尺寸与镜头，普通返回不重新居中。从记录打开页面时沿用阅读与居中流程，并区分当前内容和发布版本。历史错误只显示在历史视图。

历史视图使用现有深蓝灰表面、列表与时间线，桌面左右为任务列表和记录详情；小于700px时逐级进入详情。采集状态、列表筛选、返回入口保持可见，列表与长详情各自滚动。模型问题、概率、门槛和证据按需展开，初判通过、核验通过、发布成功分开表达；缺失时间、用量与中断结果不补造。
